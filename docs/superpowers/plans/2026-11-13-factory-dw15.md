# Abandoned Factory: the Digimon World 1.5 edition (plan 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Abandoned Factory run on Digimon World 1.5 through a `factory-15` edition, tested in the game, so the factory can ship.

**Architecture:** 1.5 already holds DG rows 222-225 itself, and its DG.SCN (LBA 162388) lies past MMM.DAT. Every zero sector after that start belongs to data 1.5 reads by LBA, so no DG table row can reach a factory script there. So `dw_newmaps.c` gets a second filter hook, on `getScript`. It serves the factory's script ids from MMM.DAT on both editions, and the stock DG table patch goes away. `tools/gen_newmap_dw15.py` is generalised to write an edition block for any new-maps package. For the factory, it copies every write and moves the four MAPHEAD sections after `glade-15`'s. The 1.5 reward box names 1.5's own item 127.

**Tech Stack:** Python 3.12, C plugin code in the port (`dw_newmaps.c`), the debug harness (`tools/dwgame.py`, `tools/field_drive.py`).

**Spec:** `docs/superpowers/specs/2026-11-11-abandoned-factory-design.md`. Plan 2 is `docs/superpowers/plans/2026-11-12-factory-screens.md`; its last table lists what is carried here.

## Facts measured for this plan (2026-11-13, 1.5 Test Build 1.3.1 image)

- 1.5 DG.SCN: LBA 162388, 839,680 B. `table[222..226]` = 0xC5800, 0xC7800, 0xC9800, 0xCB800, 0xCD000 (= file size), so rows 222-225 belong to 1.5. The sectors after it (162798+) are 1.5's unfiled data. Its zero runs at 167779 and 167940 sit next to LBAs the 1.5 EXE names (167936, 167968, 168000, 168128), so they are not free.
- `getScript` 0x80106218 and `readFileSection` are byte-identical on 1.5. `lookupFileTable` 0x800A31F8 differs in 3 bytes; filter hooks also fire on interpreted calls (`dw_newmaps.c` comment). `createSavegameChecksum` is identical. `getScript` is the only reader of `SCRIPT_OFFSET_TABLE` (`src/main/script_interp.c:647-668`). `ACTIVE_MAP_SCRIPT` is 0x80134FC2 (u16) and `MAP_SCRIPT_PTR` is 0x80134FB4 (US `symbols.txt`).
- MMM.DAT is not delta-owned on 1.5: `check_dw15_compat.py` flags only the factory's DG.SCN patch and its five MAPHEAD patches. The MMM.DAT overlays, `MAP_ENTRIES[240..243]` and the GIAS09 writes all pass on 1.5.
- 1.5's MAPHEAD tail is used to 0x60DE. `glade-15`'s 20 B section sits at 0x60DE. The factory's sections are 150 B, so from 0x60F2 they end at 0x6188, within 0x61A8.
- `DIGIMON_DATA` records 41, 115, 122, 123, 137 and 172 are identical in 1.5's live table (0x801F4300), so the cast and heap estimates hold. Items 23-28 are the same six chips. Item 127 is renamed "Glimpup Gem" (same 32 B record otherwise).
