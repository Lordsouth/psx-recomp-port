# Digimon World Vice -- GameShark / PEC cheat codes
#
# HOW TO USE: flip [ ] to [x] to turn a cheat on, then start the game.
#             Flip it back to [ ] to turn it off. Nothing else to do.
#
# These are per-frame RAM pokes, exactly like a real GameShark: the runtime
# rewrites the target values every frame on guest VBlank. That is different
# from the Digimon World Trainer in the launcher's Mods panel, which patches
# the executable once before boot. Both can be used at the same time.
#
# Addresses below were cross-checked against the dw_decomp field map, and the
# `<- field` comments name the actual struct member each code writes:
#   PARTNER_PARA   @ 0x80138460  (raise-sim state: hunger, tiredness, ...)
#   PARTNER_ENTITY @ 0x801557A8  (stats, moves, lives)
# Two published codes had an off-by-one and are corrected here -- see
# "Weight Modifier" and "Age Modifier".
#
# Supported code types: 30 (write byte), 80 (write halfword),
#                       D0/D1/D2/D3 (halfword ==, !=, <, > gate next line),
#                       E0/E1/E2/E3 (byte     ==, !=, <, > gate next line).
# Unsupported types are listed at the bottom with an explanation.


# ---------------------------------------------------------------- movies ----
# MOVIE_COMPLETED @ 0x80135304 -- the flag the movie player itself sets when a
# stream reaches its last frame (MOV_readFrame: `if (header->frameCount >=
# movie->frameCount) MOVIE_COMPLETED = 1;`). Holding it at 1 makes every movie
# finish on its first decoded frame, so the game tears the player down its own
# way instead of being interrupted.
#
# This is why it is a cheat and not a Mods-panel patch: this port is a STATIC
# recompilation, so patching an instruction in RAM does nothing -- the code was
# already compiled to native at build time. Per-frame DATA writes still work,
# which is what the GameShark engine does.
#
# Verified live: writing 01 here while the intro was playing ended it instantly.

[x] Skip all movies (boot straight to the title screen)
30135304 0001         # <- MOVIE_COMPLETED = 1

# ----------------------------------------------------------- known gaps ----
# These published codes use operations this engine does not implement. They
# are listed so nothing is silently lost -- enabling them prints a warning and
# skips only the unsupported lines.
#
# "HAPPY = DISCIPLINE" and "ENEMY GIVES MONEY = HP" open with type C2, and
# "Have All Cards (short form)" / "All Digimon Raised" use type 50 repeat
# blocks. C2 and 50 are vendor extensions whose exact semantics vary between
# GameShark revisions and PEC; implementing them from a guess would poke the
# wrong addresses. The long-form equivalents above cover the same ground.
#
# [ ] HAPPY = DISCIPLINE (unsupported: C2)

# 80138488 0000
# D2138488 0032
# 80138488 0032
# D0138488 0064
# 80138488 0063
