# Digimon World -- GameShark / PEC cheat codes
#
# HOW TO USE: flip [ ] to [x] to turn a cheat on, then start the game.
#             Flip it back to [ ] to turn it off. Nothing else to do.
#
# BACK UP YOUR MEMORY CARD FIRST if you care about the save. Several of these
# write fields the game stores on the card (stats, care state, items, story
# flags), so their effects survive being turned off again. The cards live in
# the `saves` folder next to the game; copying that folder is enough.
#
# ONE cheat ships enabled: "Skip all movies". Everything else is off.
#
# These are per-frame RAM pokes, exactly like a real GameShark: the runtime
# rewrites the target values every frame on guest VBlank. That is different
# from the Digimon World Trainer in the launcher's Mods panel, which patches
# the executable once before boot. Both can be used at the same time.
#
# CHEATS vs MODS: a cheat and a Mods-panel feature can both target the same
# thing, and then the cheat wins, because a mod patches the executable once
# before boot while a cheat rewrites RAM every frame afterwards. If a mod
# looks like it stopped working, check here first. Two cheats that write the
# same field are the same story: the later line in this file wins.
#
# Addresses below were cross-checked against the dw_decomp field map, and the
# `<- field` comments name the actual struct member each code writes:
#   PARTNER_PARA   @ 0x80138460  (raise-sim state: hunger, tiredness, ...)
#   PARTNER_ENTITY @ 0x801557A8  (stats, moves, lives)
# Two published codes had an off-by-one and are corrected here -- see
# "Weight Modifier" and "Age Modifier".
#
# Supported code types: 30 (write byte), 80 (write halfword),
#                       D0/D1/D2/D3 (halfword ==, !=, <, > gate next line),
#                       E0/E1/E2/E3 (byte     ==, !=, <, > gate next line),
#                       50 (repeat the NEXT write line: 5000CCSS, count CC,
#                           address step SS, and the value word is the
#                           per-iteration value step).
# A conditional gates only the line straight after it, so never put a D0/E0
# gate in front of a 50 -- it would consume the repeat and the write would
# happen once.
# Unsupported types are listed at the bottom with an explanation.

# MOVIE_COMPLETED @ 0x80135304 -- the flag the movie player itself sets when a
# stream reaches its last frame (MOV_readFrame: `if (header->frameCount >=
# movie->frameCount) MOVIE_COMPLETED = 1;`). Holding it at 1 makes every movie
# finish on its first decoded frame, so the game tears the player down its own
# way instead of being interrupted.
#
# This is why it is a cheat and not a Mods-panel patch: this port is a STATIC
# recompilation, so patching an instruction in RAM does nothing -- the code was
# already compiled to native at build time. Per-frame DATA writes still work,
# which is what the GameShark engine does.
#

# 0x80135450 is the RAW pad word and it is ACTIVE LOW: PadRead (0x80091BF8)
# reads it and NORs it to make POLLED_INPUT, so the mask here is inverted.
#
# The bit layout is the PsyQ one, NOT the raw hardware mask, because the pad
# buffer is byte-swapped relative to it. Read it off the game's own code:
#   inventory.c:766-773  moveMenuCursor -- 0x1000 moves a menu cursor UP and
#                        0x4000 moves it DOWN, so those are the D-PAD
#   map.c:1272           newly-pressed 0x40 extends the interaction box along
#                        the way the player faces, so 0x40 is CROSS
#   script_common.c:404+ 0x40 confirm, 0x10 cancel, 0x1000/0x4000 up/down,
#                        0x800 Start
# So: Triangle 0x10, Circle 0x20, Cross 0x40, Square 0x80; Up 0x1000,
# Right 0x2000, Down 0x4000, Left 0x8000. "Circle alone" is therefore
# ~0x0020 = 0xFFDF.
#
# A 0.3.4 pass briefly changed this to 0xDFFF on the assumption that the
# hardware layout applied (Circle = 0x2000). It does not, and 0xDFFF is D-pad
# RIGHT -- which would have ended the run the first time the player walked
# right. Reverted the same day. The lesson is in docs/INTERNALS.md 6.4: read
# the code that CONSUMES the field, not a convention you expect it to follow.
[ ] Press O to beat the game
D0135450 FFDF          # if Circle (0x20 active-high), and only Circle, is held
80134EB4 0003          #   set the ending flag
